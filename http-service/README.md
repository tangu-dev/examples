# HTTP Service

An HTTP web service built with `/web/app`, demonstrating declarative routing (`router`), reverse routing (`url-for`), `#shtml` markup rendering (`respond-html`), JSON responses (`respond-json`), custom 404 handling, and embedded server hosting (`serve`).

## Run

```sh
tangu run http-service
tangu run http-service 8080
```

## Test

```sh
tangu test http-service
```
